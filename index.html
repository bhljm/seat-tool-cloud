📷 學生照片檔名規則
學生照片可維持 Google Drive 私人權限，不需要設為「知道連結的人可檢視」。照片由安全後端在白名單驗證通過後代理載入；一般使用者不需要直接取得 Drive 權限，也不需要額外操作。檔名需含座號，最推薦 01.jpg～30.jpg；也支援 1.jpg、60101.jpg、601-05.jpg、601_18.jpg 等格式。
🧰 後端工具連結
工具清單由後端名冊試算表的「工具連結」工作表管理。修改啟用、排序、名稱與網址後，再測試連線或重新同步名冊即可更新。
🗂️「管理」選單怎麼用？
「管理」內的新增班級、重新命名、移除班級與手動名冊，只調整目前瀏覽器工作階段；再次按「同步」時，班級與姓名仍會以後端名冊為準。
「保存／開啟本機專案」與「匯出／匯入座位備份」會把座位配置保存到本機檔案，可能含學生資料，請勿放到公開 GitHub、公開雲端資料夾或轉傳給未授權人員。

🔧 GAS 部署提醒｜DEFAULT_GAS_URL 從哪裡取得？
雲端安全版已把名冊來源改由後端「系統設定」的 SPREADSHEET_ID 管理，日常使用不再輸入試算表 ID。DEFAULT_GAS_URL 仍是前端連到安全後端的 Web App 網址。
取得方式：
1. 開啟後端「班級學生名冊」Google 試算表。
2. 點選「擴充功能 → Apps Script」。
3. 在 Apps Script 右上角點「部署 → 管理部署作業」。
4. 找到目前使用中的「網頁應用程式」部署。
5. 複製其中的「網頁應用程式網址（Web app URL）」，網址通常以 https://script.google.com/.../exec 結尾。
6. 這一步只在「第一次部署」或「建立全新 Web App 部署」時需要：由管理者在 HTML 的 DEFAULT_GAS_URL 設定一次。日常使用者不需要填寫 GAS 網址。
注意：若只是「管理部署作業 → 編輯 → 新增版本 → 部署」，通常沿用原部署網址，不必修改；若使用「新增部署」建立新的 Web App，網址可能改變，就要同步更新 DEFAULT_GAS_URL。
簡單記法：GAS 網址屬於「部署設定」，不是「使用者設定」；設定一次後，GitHub Pages 日常使用不再處理它。
目前雲端版 v1.0 正確流程：先在後端「系統設定」填入 GOOGLE_CLIENT_ID、ALLOWED_EMAILS 與 SPREADSHEET_ID → Web App 以擁有者身分執行、存取權限設為「所有人」 → HTML 固定填入 Web App URL → 使用者從 GitHub Pages 以白名單 Google 帳號登入。未通過後端 Token 與白名單驗證時，不回傳學生資料。 學生照片不回傳 Drive 直連網址，而是經相同白名單驗證後由後端安全載入。
